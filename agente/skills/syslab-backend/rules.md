# 🤖 Reglas del Agente de IA — SysLab 2.0

## Reglas de Comportamiento del Backend y Persistencia:
1. **Modelado de Datos:** Las entidades del sistema (Tareas y Usuarios) deben manejarse estrictamente con Prisma ORM sobre PostgreSQL.
2. **Arquitectura:** Respetar la orquestación multi-contenedor mediante Docker Compose definida en SysLab 2.0.
3. **API RESTful:** Desarrollar endpoints limpios para el CRUD de tareas (Crear, Leer, Actualizar, Eliminar).
4. **Commits:** Seguir el estándar Conventional Commits en idioma español.
